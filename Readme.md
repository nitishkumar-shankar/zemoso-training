# SAMPLE REACT APPLICATION

This is a sample React application which contains a form with a text input field for entering a name. When you type a name and submit the form, the app will show an alert with the entered name.

## Features

- Text input field to enter your name.
- Submit button to trigger an alert with the provided name.
- Used Atoms- Input field and submit button
- Used Molecules - Name form
